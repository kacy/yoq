# yoq 0.2.1

this patch release brings the published binaries up to date with the reliability and security fixes since 0.2.0. it also restores compatibility with the verified one-line installer.

## installation

```bash
curl -fsSL https://yoq.dev/install | bash
```

release archives include checksums, signed provenance metadata, and a software bill of materials. the installer verifies the publisher and checks that the downloaded archive belongs to the selected release before extracting it.

the release workflow checks artifact attestations before publication and tests the public installer afterward. the installer reports missing metadata and failed verification directly.

## fixes and improvements

- container startup, process cleanup, cancellation, and resource ownership
- image layer extraction, registry certificate verification, and native filesystem handling
- cluster registration, scheduling, state replication, and assignment recovery
- service discovery, network policy updates, and kernel networking behavior
- dependency checks, authenticated operations, and release verification
- clearer documentation for setup, deployment, and the limits of gpu, training, and storage support

## requirements

linux kernel 6.1+ with cgroups v2 is required. local containers need root privileges. the installer needs curl, python3, and an authenticated github cli with attestation support (`gh auth login`). building from source requires zig 0.16.0.

back up yoq state and application data before upgrading. database backups do not include application volumes or object data. yoq remains under active hardening; validate your workloads and recovery procedures on the hosts you use.
