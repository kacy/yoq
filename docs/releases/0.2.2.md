# yoq 0.2.2

this patch release publishes the local container workflows and the security, reliability, and cluster fixes made since 0.2.1. it also moves the source build to zig 0.17.0 and sqlite to 3.54.1.

## installation

```bash
curl -fsSL https://yoq.dev/install | bash
```

release archives include checksums, signed provenance metadata, and a software bill of materials. the installer verifies the publisher and checks that the downloaded archive belongs to the selected release before extracting it.

## changes to check before upgrading

- on hosts where the `INPUT` policy drops traffic, such as hosts using ufw, yoq adds one tagged iptables rule so containers can reach the bridge dns resolver. it reports the change, records it in the audit log, and removes the rule with the network. set `YOQ_HOST_FIREWALL=off` to manage the firewall yourself. [container networks](../container-networks.md) lists the rules yoq changes and the rules that stay until reboot.
- containers no longer fall back to the `8.8.8.8` nameserver.
- `DAC_OVERRIDE` is now a default capability, so root entrypoints can write to files owned by other users.
- named manifest volumes are now mounted read-write, including `driver = "host"` volumes. bind mounts stay read-only.
- cluster deploys now refuse host path mounts without `cluster:admin` and an agent allowlist, and refuse relative bind sources.
- applies now fail on a missing or invalid image instead of skipping the workload.
- app and volume names that would escape the volume root are now refused.

## fixes and improvements

- local containers: expanded workflows, session reliability, process diagnostics, and exit reporting for manifest services
- published ports for health-checked manifest services, which stayed rejected after the service became healthy
- container isolation: seccomp gaps, host-global `/proc` entries, inherited descriptors, and helpers reachable from container root
- image builds and layers: `COPY` source handling, symlinks, malformed pax headers, and `yoq cp` symlink handling
- cluster: offline recovery, bounded raft catch-up, gossip identity and failure detection, agent connectivity, and crash fixes
- proxy and tls: peer certificate verification, http2 flow control and compression state, and streaming with backpressure
- sqlite advisories fixed in 3.54.0 and later

## known issues

- after containers are removed, the service audit can log repeated `audit mismatch` warnings every 30 seconds.
- manifest ports cannot bind to one address, so published ports listen on all interfaces.

## requirements

linux kernel 6.1+ with cgroups v2 is required. local containers need root privileges. the installer needs curl, python3, and an authenticated github cli with attestation support (`gh auth login`). building from source requires zig 0.17.0.

back up yoq state and application data before upgrading. database backups do not include application volumes or object data. yoq remains under active hardening; validate your workloads and recovery procedures on the hosts you use.
